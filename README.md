# popo 首页体验升级 · 交互 Demo 提案

这是一份针对 popo 首页体验升级的 Demo 提案。它用一个可以直接操作的高保真页面，呈现升级后的首页浏览、作品卡片、合集、消息通知和发布入口，让方案里的尺寸、层级、动效和状态切换都能在浏览器里被实际体验和讨论，而不是只靠截图和文字描述。

页面里的数据全部是 mock，不连接任何真实业务，也不会写入任何数据。

## 在线体验

- https://aerol1n.github.io/popo-homepage-upgrade-demo/
- 建议使用 Chrome / Edge 最新版，桌面端 1440px 及以上宽度。
- 首次进入会播放一段开屏动画和头像引导，只出现一次。

## 提案内容

**首页**

- 三段式结构：本周精选合集、热门搜索、探索作品。合集默认展示 3 张封面，鼠标悬停后展开为 5 张加「查看全部」。热门搜索是通栏自动滚动的横幅，悬停暂停。
- 导航栏按滚动方向切换三种状态：页面顶部显示完整导航，向下滚动时隐藏，向上滚动时只保留搜索框。
- 搜索框居中放在导航栏里，logo 是下拉菜单，消息按钮悬停时弹出通知浮层。
- 作品流支持分类标签和排序（综合推荐、最新发布、最多打气）。排序只保留卡片上能直接看到数字的维度。

**作品卡片的悬停聚焦**

- 悬停的卡片轻微放大并提起，封面内容开始向下滚动，像在演示这个作品。
- 周围的卡片被轻轻挤开、略微缩小，并按离它的远近逐渐变淡，离得越远越淡，形成以鼠标为中心的聚焦。移开后全部恢复。
- 仅在带鼠标的设备上启用，开启系统「减少动态效果」时自动关闭。

**合集专区页**

- 中轴时间线：作品左右交错排列，中轴随滚动填色，离视口中线最近的作品编号高亮。
- 三种排序：编辑推荐、最多打气、最多浏览，切换时卡片带位置移动动画。
- 页头汇总数据、合集切换、分享合集链接，页尾推荐其他合集。

**其他**

- 个人主页、作品详情、评论抽屉。
- 消息通知浮层：评论、打气、徽章、系统通知和每周冒泡。
- 「发个泡泡」入口及相关视觉动效。
- 内页左上角统一为返回首页的图标按钮。

## 本地运行

这是一个纯静态页面，没有构建步骤。在仓库根目录执行：

```bash
python3 -m http.server 8765 --directory demo
```

然后打开 http://127.0.0.1:8765/ 。也可以用任意静态服务器托管 `demo` 目录，根目录的 `index.html` 会自动跳转到 `demo/index.html`。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 跳转到 `demo/index.html` 的入口，供 GitHub Pages 使用 |
| `demo/index.html` | Demo 主页面，单页应用，页面之间用 hash 路由，例如 `#/works/7188`、`#/profile`、`#/collections/play` |
| `demo/app.js`、`demo/styles.css` | 交互逻辑和样式 |
| `demo/assets/` | 图片、图标、插画等素材 |
| `demo/inbox-prototype/` | 消息通知浮层，以 iframe 嵌入主页面 |

## 说明

- 部分按钮只用于演示页面跳转或状态变化，重点是验证交互路径、反馈节奏和视觉关系。
- 个别入口是占位，点击后没有任何反应，这是有意为之。
- 本仓库是设计提案的演示载体，不代表最终实现。
